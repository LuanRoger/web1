# Projeto 3

## Como rodar o projeto

1. Abra o terminal e navegue até a pasta do projeto.
2. Execute o comando `npm install` para instalar as dependências.
3. Execute o comando `npm dev` para iniciar o servidor de desenvolvimento.
4. Use o LiveServer do VSCode para incializar o site.

### Observações

- Certfiquese de que o LiveServer está configurado para abrir o arquivo `index.html`.
- Certifique-se que o servidor esta rodando na porta correta: `3000`.
